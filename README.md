# 국악기 소리 탐색

꽹과리·장구·북·징·소고·태평소의 기본 소리와 연주를 듣는 비상업용 교육 웹앱입니다.

## GitHub Pages 사용

별도 설치나 빌드가 필요 없는 HTML·CSS·JavaScript 앱입니다. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하면 됩니다. 배포 주소는 GitHub Pages 설정 화면에서 확인하세요.

모든 사진·음원은 저장소에 포함되어 있으며, 상대 경로를 사용하므로 프로젝트 하위 경로에서도 동작합니다. 서체는 Google Fonts에서 불러오며, 연결되지 않으면 시스템 서체를 사용합니다.

## 기능

- 시작 화면의 활동 지시문과 악기 탐색 화면
- 여섯 악기의 사진, 기본 소리 듣기, 연주 듣기
- 컴퓨터·패드·휴대폰에 맞춘 반응형 배치
- 같은 버튼 재클릭, 다른 영역 클릭, 화면 이동, Escape 입력 시 재생 정지
- 동시에 한 음원만 재생
- 악기의 특징과 음색을 표현하기 위한 안내문

## 파일

- `index.html`: 화면과 출처 안내
- `styles.css`: 디자인과 반응형 배치
- `app.js`: 화면 전환 및 음원 재생
- `assets/images/`: 악기 사진
- `assets/audio/`: 앱 재생용 MP3 12개
- `assets/audio-sources.json`: 음원별 출처·이용 조건·편집 기록
- `assets/image-sources.json`: 사진 원본 비율 확인 기록

## 사진·음원 이용 조건

각 자료의 권리와 이용 조건은 원저작자에게 있습니다. 이 저장소 전체를 하나의 자유 이용 라이선스로 제공하는 것은 아닙니다. 자세한 출처는 앱 하단의 **사진·음원 출처**와 `assets/audio-sources.json`을 확인하세요.

- 꽹과리·장구·북·징·태평소 사진: 국립국악원 사진자료실 「한국의 악기」, 공공누리 제1유형(출처표시).
- 소고 사진: 국립국악원 국악박물관, 국악사전 「소고」의 소고(벅구) 사진. 공공누리 제4유형(출처표시·상업적 이용금지·변경금지). 사진 파일은 변형하지 않았습니다.
- 꽹과리·장구·북·징·태평소 음원: 국립국악원 국악기 디지털 음원, 공공누리 제1유형. 구간 추출·음량 조절·페이드·형식 변환을 수행했습니다.
- 소고 음원: [Korean Sogo Drum (jajinmori jangdan-style)](https://freesound.org/people/ultradust/sounds/167382/) by ultradust / Freesound, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). 공개 MP3 미리듣기를 사용했으며 구간 추출·음량 조절·페이드·형식 변환을 수행했습니다. 제작자는 정확한 자진모리 장단이 아니라고 명시했으므로, 소고 리듬 예시로 활용하세요.

이 앱은 비상업용 교육 활동을 위해 제작되었습니다.
